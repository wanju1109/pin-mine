# 금광 두더지 - Pin Mine

핀을 뽑아 금을 두더지의 수레에 담는 휴대폰용 퍼즐 게임입니다. `index.html` 한 파일(Canvas, 외부 라이브러리 없음)로 동작합니다.

- 조작: 핀 탭(휴대폰) / 숫자키 1~9로 핀 뽑기, Z 한 수 되돌리기, H 힌트, R 다시, Enter 확인(PC). 하단 버튼으로도 모두 조작할 수 있습니다.
- 규칙: 용암이 수레에 닿으면 실패, 물을 부으면 용암이 돌로 굳고, 금이 용암에 닿으면 재가 됩니다.
- 초반 4판은 순서·물과 용암·갈라진 출구·숨은 용암을 배우는 수제 퍼즐입니다. 이후에는 풀이를 검증한 자동 생성 퍼즐이 이어지고, 6레벨부터 제한 시간이 생깁니다.
- 한 수 되돌리기는 재료·핀·남은 시간·실패로 잃은 하트까지 복원합니다. 실패 화면의 되돌리기 문구를 탭해도 됩니다. 힌트는 재료가 멈춘 뒤 현재 판을 풀어 다음 핀을 표시합니다.
- 힌트나 되돌리기 없이 연속 클리어하면 두 번째 판부터 최대 500점의 보너스를 받습니다. 하트는 5레벨마다 1개 회복됩니다. 최고 기록은 클리어할 때 저장합니다.
- 청록색 광산, 목재 프레임, 황금 입자, 광부 캐릭터와 수집·클리어 효과를 Canvas로 그립니다. 소리 켜기/끄기와 지원 기기의 진동을 제공합니다.
- 화면 양쪽에 최소 24px 여백을 두어 iframe이 들어간 모바일 페이지를 스크롤할 수 있습니다. 세로 터치 스크롤을 허용하며, 핀은 스크롤이 아닌 탭을 마쳤을 때 뽑힙니다.

검증: 저장소 폴더에서 `python -m http.server 8000 --bind 127.0.0.1` 실행 후 [자동 테스트 페이지](http://127.0.0.1:8000/tests/qa.html)를 엽니다. 400×720 iframe에서 L1~12 풀이, 힌트, 되돌리기, 실패·게임 오버·재시작을 확인합니다. 테스트는 브라우저 안에서만 실행하며 저장 기록에 테스트 점수가 남을 수 있습니다.

임베드 예시:

```html
<iframe src="https://wanju1109.github.io/pin-mine/" width="400" height="720" style="border:0;max-width:100%" allow="autoplay"></iframe>
```
